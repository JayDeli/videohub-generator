How to use this — fill the table, make the files, load the Videohub

A · Fill in the table (in Lucid, or right here)

  1. IN LABEL: name each source feeding the router (what is on that input). Keep each name unique. Leave unused inputs as IN 15 etc.
  2. FROM (PATCH): where that input is cabled from (for example SW 1.1). Notes for the tech only; it does not go to the router.
  3. OUT LABEL: name each destination (what that output feeds). Keep each name unique. Leave unused outputs as OUT 15 etc.
  4. XPT: the input number that this output should take. Blank = leave that output unchanged. ROUTED SOURCE is only a reading aid, so it can be left blank; this page works it out from XPT.
  5. Rows are ports: row 05 on the left is input 5, row 05 on the right is output 5. They are separate, not connected to each other. Pick your router's size in step 1 (10, 20, 40, 80, 120, the Minis, or any custom size).

B · Make the files

  1. In Lucid select the table cells, copy, then press Ctrl+V (Cmd+V) on this page. You can also paste a Videohub Setup label set or a report copied from the Videohub itself; the page works out the size. Or open the link someone sent you and the table is already loaded.
  2. Fix anything marked ERROR (red) before downloading. Warnings are advice only. Edit directly in the grid if something is wrong; the preview shows exactly what the router will do.
  3. Download the label set (for Videohub Setup, labels only) or videohub_load.txt (labels and routes, sent over the network).

C · Load it onto the Videohub

Loading replaces labels (and routes) on the unit. Use step 5 to back up what is on it first, and try the file on a bench unit before show day.

  1. Labels only, in Videohub Setup: open Blackmagic Videohub Setup, click Settings (the gear icon) and choose load label set, then pick the label set file. A label set holds labels only, so set the routes with route 2 below, Videohub Control, the front panel or your control panel. (Menu names can differ between software versions.)
  2. Labels and routes, over the network: put your computer on the same network as the Videohub and run the small helper script (needs Python 3): python3 videohub_push.py videohub_load.txt 192.168.x.x using the Videohub's IP address. You should see lines ending in ACK. Download videohub_push.py. Step 5 also shows a one-line terminal command that needs no Python.
  3. By hand: use the Route preview below as a checklist.
  4. After loading, use step 5 to read the router back and compare it with the table, then spot-check three or four outputs on a monitor.

Copy back into Lucid

Optional. Copies the table so you can paste it into the Lucid router table. Steps: (1) click the first cell under the header (▶ IN 01), press Esc once so the cell is selected but not being typed in, then paste (Ctrl/Cmd+V).
